# videomerge
This is a c# program to automize merging videos quickly using Gyan.FFmpeg without directly typing complex command on powershell.
It will automatically use rtx series gpu if available.
C# .NET framework 4.7.2 required(Usually automatically installed for windows 10,11)
It needs Gyan.FFmpeg, so install it using this command.
```powershell
winget install Gyan.FFmpeg
```
